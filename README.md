A comprehensive analysis of global layoff trends from 2020 to 2023, examining patterns across companies, industries, countries, and funding stages.

## 📊 Project Overview

This project analyzes workforce reduction trends across multiple dimensions to understand the impact of economic shifts on various sectors. The analysis reveals that **2022 was the peak year for layoffs**, with significant variations across industries and geographies.

**Key Metrics:**
- 📈 **383,159** total employees laid off
- 🌍 **4M+** working employees tracked
- 🏢 **116 companies** with 100% workforce reduction
- 📅 **March 2020 - March 2023** analysis period

🚀 Installation & Usage

Prerequisites
- MySQL Server 8.0+
- Power BI Desktop
- Git

Step-by-Step Setup

Clone the repository

```bash
git clone https://github.com/mohamed-ali-505/layoffs-analysis.git
cd layoffs-analysis
```

Database Setup

```bash
# Import the dataset into MySQL
mysql -u your_username -p < data/raw/layoffs_raw.sql

# Run cleaning and analysis scripts
mysql -u your_username -p < sql_scripts/data_cleaning.sql
mysql -u your_username -p < sql_scripts/analysis_queries.sql
```

Power BI Dashboard

Open powerbi/layoffs.pbix in Power BI Desktop

Refresh data connections to point to your MySQL instance

Explore the 7 interactive dashboard pages

# 📊 Key Findings

🔥 Major Insights
- 2022 Peak Year - Highest layoffs with significant workforce reductions
- Consumer & Retail Dominance - Most affected sectors consistently
- US Leadership - 66.87% of all tracked layoffs occurred in United States
- Funding Disconnect - No direct correlation between funds raised and layoff numbers
- November 2022 Spike - Highest single-month layoffs (53,451 employees)

📈 Trend Analysis
Rolling Total shows steady accumulation reaching 383,159 by March 2023

Seasonal Patterns observed with Q1 often showing higher layoffs

Industry Shifts from Travel (2020) to Tech (2022-2023)
